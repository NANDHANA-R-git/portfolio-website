# Responsive Personal Portfolio Website

A responsive personal portfolio website built as part of the **Web Development Internship** at **Codomax Digital Solutions** (July 2026).

🔗 **Live Site:** https://nandhana-r-git.github.io/portfolio-website/

## About

This is my personal portfolio site, showcasing my background in Electronics and Communication Engineering (ECE), my VLSI/embedded projects, my web development internship work, and ways to get in touch. Built from scratch over a 14-day internship program, starting with plain HTML and progressively adding CSS styling, responsive layouts, JavaScript interactivity, and deployment.

## Tech Stack

- **HTML5** - semantic page structure
- **CSS3** - custom properties, Flexbox, Grid, media queries, transitions/animations
- **JavaScript (Vanilla)** - DOM manipulation, form validation, Intersection Observer for scroll animations
- **Google Fonts** - Poppins & Inter
- **GitHub Pages** - deployment

## Features

- Fully responsive layout (mobile, tablet, desktop)
- Smooth scrolling navigation with active-link highlighting
- Skills section organized by category
- Projects section with real academic and internship projects
- Resume download button
- Experience timeline
- Contact form with custom JavaScript validation
- Scroll-triggered fade-in animations
- Scroll-to-top button

## Getting Started

To run this project locally:

1. Clone the repository
   ```bash
   git clone https://github.com/NANDHANA-R-git/portfolio-website.git
   ```
2. Open the folder in VS Code
3. Right-click `index.html` and select **Open with Live Server** (or simply open `index.html` directly in your browser)
